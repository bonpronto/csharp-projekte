# csharp-projekte

Das sind meine eigenen C#-Programme, die ich zum Lernen und Ausprobieren schreibe.

## Inhalt

Jedes Programm liegt in einem eigenen Ordner und hat seine eigene Projektdatei (`.csproj`).

## Starten

1. Repository herunterladen (**Code**, dann **Download ZIP**) oder mit Git klonen.
2. Den gewünschten Ordner öffnen und die `.csproj`- oder `.sln`-Datei mit Visual Studio starten.
3. Mit `F5` ausführen.

## Voraussetzungen

- Windows
- Visual Studio mit C# (.NET Framework)
